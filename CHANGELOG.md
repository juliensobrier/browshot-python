# Changelog

## 1.32.0

- Port the current Browshot client to Python 3 and keep the `browshot` import and existing method signatures.
- Add `screenshot_pdf`, `screenshot_pdf_file`, `screenshot_video`, and `screenshot_video_file` for PDF, WebM, MP4, and GIF.
- Document API 1.32 capture options, native country instances, and credit costs.
- Add offline request and artifact tests and opt-in live tests using `BROWSHOT_API_KEY`.
